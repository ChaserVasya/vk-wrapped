# VK Wrapped

Flutter приложение для анализа данных из VK (ВКонтакте) - аналог Spotify Wrapped, но для социальной сети ВКонтакте.

## Описание

VK Wrapped - это приложение, которое анализирует вашу активность в ВКонтакте и создает персонализированную статистику, включая:

- Самые популярные посты
- Частота публикаций
- Анализ аудитории
- Статистика взаимодействий
- И многое другое

## Технологии

- **Flutter** - кроссплатформенная разработка
- **Dart** - язык программирования
- **VK API** - интеграция с ВКонтакте

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ChaserVasya/vk-wrapped.git
cd vk-wrapped
```

2. Установите зависимости:
```bash
flutter pub get
```

3. Запустите приложение:
```bash
flutter run
```
